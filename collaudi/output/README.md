# Output reali dei collaudi P001–P100

Indice leggibile dei risultati effettivamente prodotti dai collaudi. Ogni progetto ha una pagina con provenienza, ambiente, comando, exit code e stdout/stderr delle sue suite. Demo, compilazione e controlli runtime sono presentati separatamente.

- **P001–P080:** [run 39849393701](https://github.com/davideiannella/100-progetti-informatica-pratica/actions/runs/39849393701), commit `44cd421247ca2bfe838baa735cf6180134f80464`: 80 progetti superati, 5 job su 5. Sono 101 processi di suite originali: 39 rapporti unittest con 1420 metodi e 62 programmi di assert; in aggiunta 2 suite sui motori database (18 asserzioni), 21 controlli runtime e 29 demo. Queste categorie non vengono sommate in un unico conteggio.

- **P081–P100:** [run 39893701054](https://github.com/davideiannella/100-progetti-informatica-pratica/actions/runs/39893701054), commit `3ab7bdfedb20a443bd71fe4e4ffe3c1dd67bd707`: Ubuntu e Windows, Python 3.12 e 3.13. Ogni combinazione ha 20 suite, **377 nomi/esiti di metodi unittest effettivamente emessi**, nessuno skipped, 299 hash sorgente verificati e 60 file Python compilati.

Nessun test è stato rieseguito per generare questa raccolta. I vecchi rapporti compatti a punti e i programmi di assert non forniscono tutti i nomi dei sottocasi: qui non vengono inventati. `unittest` usa normalmente **stderr** anche per i test superati. I file TXT sono non compressi; gli stream vuoti sono indicati fuori dai blocchi di output.
