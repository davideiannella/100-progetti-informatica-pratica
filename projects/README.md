# Sorgenti dei 100 progetti

[Pagina principale](../README.md) · [Catalogo completo](../docs/CATALOGO.md) · [Collaudi](../COLLAUDO/README.md)

Le cartelle P001–P100 contengono i laboratori del libro. Ogni README indica requisiti, preparazione, avvio e test. Apri il catalogo per scegliere un progetto per titolo e ambiente, poi esegui i comandi dalla cartella indicata.

I risultati documentati si trovano nella cartella COLLAUDO con lo stesso identificativo del progetto.
